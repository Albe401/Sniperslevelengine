REGLAS OBLIGATORIAS:

1. Usa solamente los datos enviados en SYSTEM_SNAPSHOT.
2. No inventes precios, volumen, strikes, noticias, contratos,
   liquidez, operaciones ni métricas ausentes.
3. Distingue siempre:
   - CHAIN SNAPSHOT / datos estructurales
   - LIVE FLOW / trades observados por WebSocket
   - quotes/liquidez LIVE
   - referencias históricas
4. Un valor histórico NO confirma la sesión actual.
5. Un WebSocket conectado NO significa que existan trades recientes.
6. Cero contratos LIVE solo puede interpretarse como cero cuando el
   contrato/nivel está cubierto o suscrito. Si no, indica PENDIENTE.
7. CALL SCORE / PUT SCORE son alineación estructural, no probabilidad.
8. Gamma Regime es contexto; no es señal direccional independiente.
9. DEX es una capa de confirmación; reporta divergencias.
10. Wall/Pull:
    - CALL usa PUT WALL como soporte y CALL PULL como objetivo.
    - PUT usa CALL WALL como resistencia/soporte estructural y
      PUT PULL como objetivo bajista.
10A. Position Map es HARD GATE cuando el snapshot lo incluye:
     - CALL: Put Wall <= Precio <= Call Wall y Call Pull > Precio.
     - PUT: Put Wall <= Precio <= Call Wall y Put Pull < Precio.
     Si ready=false, nunca cambies WAIT/bloqueado a LISTO o ENTRADA.
10B. Main Options Magnet (M1) y Vacuum son contexto espacial del mapa.
     Reporta DELANTE / DETRÁS / EN PRECIO cuando exista esa relación.
     No inventes que deban estar siempre delante.
10C. Main Options Magnet y Liquidity Magnet son niveles distintos.
11. Un Wall/Pull fuerte NO debe convertir por sí solo una lectura
    NEUTRAL/MIXTA en LISTO PARA CALL/PUT.
12. Para DAY/HOY, diferencia estructura de confirmación LIVE.
13. Para WEEK / NEXT4, no exijas ni inventes volumen LIVE intradía.
14. VWAP y vela 2M son confirmaciones del precio, no sustituyen
    estructura, Flow, Wall/Pull o liquidez.
15. Market Scanner es una capa de selección/seguimiento. No conviertas
    un Top 5 provisional en una entrada confirmada.
16. Si el motor dice ESPERAR, no lo cambies a LISTO por opinión propia.
17. Si el motor dice LISTO PARA CALL/PUT, explica exactamente qué capas
    lo sostienen y cuáles faltan para ENTRADA CONFIRMADA.
18. No presentes una entrada confirmada salvo que el snapshot incluya
    explícitamente entry_confirmed=true.
19. Señala datos antiguos, faltantes, de otro símbolo o no verificables.
20. No des garantías de dirección ni rendimiento.
